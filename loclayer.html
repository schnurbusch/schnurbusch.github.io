LocLayer

Localize without refactoring. No keys, no wrapper calls, no rewrite.

You want your game in three languages by Friday, not a migration to a localization framework. LocLayer is a translation layer: your code keeps setting UI strings exactly as it does today, and LocLayer swaps them on screen at runtime.

Register a language and add translations, either in code or from a CSV your translator fills in Excel. The bundled scanner finds every TextMeshPro and uGUI text and translates it live. Anything not translated yet simply stays in your source language, so you can localize incrementally and ship at any point.

It was extracted from a shipped game, Famechaser, where this exact system localized around a thousand strings without touching a single call site.

What you get

  • Full C# source in four small assemblies, no DLLs and no dependencies beyond uGUI and TextMeshPro
  • Auto scanner for TMP_Text and legacy Text: translates, tracks changes and restores originals when you switch back. Input field text is skipped automatically, and a LocIgnore component handles manual exclusions
  • Four stage matching: exact, affix tolerant, rich text segmentation, and regex patterns for dynamic strings such as score lines, including evaluator hooks
  • CSV import built for translators: comma, semicolon and tab are auto detected, quotes and line breaks are handled, and an editor tool exports all scene texts as a ready to fill template
  • Any number of languages with any codes, persistence between sessions, operating system language detection on first launch, and a language changed event
  • Interactive demo that switches English to German, Spanish and French with one click per language
  • Manual as PDF and Markdown, honest about the limits

What it is not

A full asset localization suite with localized sprites, audio and plural rules. It does one thing quickly: getting your existing string UI translated with minimum effort.

Requirements

Unity 6 or newer, working with both input backends. TextMeshPro ships with the uGUI package in Unity 6. Pure C#, works on all platforms including WebGL and mobile.
