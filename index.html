Unity tools and games, full C# source

I am Daniel Schnurbusch, a solo developer working in Unity and C#. Every tool here started as a problem in one of my own projects, got solved once properly, and was then pulled out and documented so it works in yours too.

No DLLs, no black boxes, no runtime dependencies beyond what Unity already ships.

Tools

Six editor and runtime tools for Unity 6 and newer. Each one does a single job and stays out of the way.

ChipForge

Chiptune sound effects and looping music synthesized at runtime. No audio files in the build at all.

Details

LocLayer

Localization as a layer over your existing UI. No keys, no wrapper calls, no rewrite of code you already shipped.

Details

PortraitFit

A WebGL template for portrait games. Clean letterbox bars on desktop, full screen on phones, no distortion anywhere.

Details

HintOnce

First-time hints in one line of code. No prefab, no canvas, no manager, and each hint shows exactly once.

Details

RowPool

Virtualised lists for uGUI. A hundred thousand entries cost the same seventeen GameObjects as twenty do.

Details

SettingsNow

A settings menu in one line, key rebinding included. Your own settings need one attribute on a variable you already have.

Details

Games

Where the tools come from.

Famechaser

A streaming simulation about the tug of war for viewers, followers and fame. Built in Unity, playable in the browser. ChipForge, LocLayer, PortraitFit and HintOnce all began as parts of this game.
